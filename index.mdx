Mirror Fit is a full-stack virtual try-on platform built with Flutter, Python, and open-source AI. Shoppers see garments on their body in real time through the camera, generate AI avatars with their face, and receive a quantified fit score — all on-device or via self-hosted GPU backends, with no paid third-party APIs.

## What Mirror Fit Does

Mirror Fit combines four independent systems into one seamless experience:

<CardGroup cols={2}>
  <Card title="Real-Time AR Try-On" icon="shirt">
    MediaPipe pose detection + TFLite body segmentation overlay garments at 30 FPS directly in the camera feed — no cloud round-trip needed.
  </Card>
  <Card title="AI Avatar Generation" icon="user-astronaut">
    Upload a selfie, pick a body shape, and get a full-body avatar via InsightFace face swap with LAB colour-space skin-tone matching.
  </Card>
  <Card title="Fit Scoring" icon="ruler">
    A logistic regression model trained on industry ease allowances grades chest, shoulder, length, and sleeve ratios, returning a 0–100 fit score and a five-tier label.
  </Card>
  <Card title="Returns-Risk Analysis" icon="shield-check">
    A cost-sensitive binary classifier flags suspicious return requests for human review — never auto-denying a refund — keeping false positives below 0.05%.
  </Card>
</CardGroup>

## Get Started

<Steps>
  <Step title="Install Flutter and Python dependencies">
    Run `flutter pub get` in the project root and `pip install -r requirements.txt` in each backend directory.
  </Step>
  <Step title="Add ML model assets">
    Place `selfie_segmentation.tflite` in `assets/ml_models/` and your Blender-exported `.glb` garment files in `assets/models/`.
  </Step>
  <Step title="Start the backends">
    Launch the face-swap and try-on backends with `start_all.ps1` (Windows) or individually via `uvicorn` on Linux/macOS.
  </Step>
  <Step title="Run on device">
    Connect an Android or iOS device and run `flutter run`. Tap **Live Try-On** on the home screen to start.
  </Step>
</Steps>

<Note>
Mirror Fit requires a physical device — camera-dependent features do not work on simulators or emulators.
</Note>
